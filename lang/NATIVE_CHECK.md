# Interface strings that need a native-speaker check

Every Spanish and Romanian string in `lang/es.json` and `lang/ro.json` is a machine
translation until a native speaker has checked it. This is the TODO list: when a string is
checked, move it to the "Checked" section. A test makes sure every string in those files is
listed in one section or the other, so nothing is added unreviewed by accident.
